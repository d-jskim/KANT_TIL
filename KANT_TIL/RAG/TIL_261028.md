
# 튜터님 코멘트(실무)
- Instruction에 금지 사항을 명시해도 모델이 지시를 어기는 경우가 발생함.
- Instruction의 문장 표현에 따라 결과가 달라지므로 신중한 설계가 필요함.
- 초기 비즈니스 단계부터 고객·사용자의 선호도 데이터를 수집하는 것이 중요함.
- LLM을 활용해 단기·장기 메모리 저장 대상을 판단하고 분기 처리할 수 있음(Jev 등 활용).
- 새로운 기술·서비스를 적극적으로 사용해 보고, 기존의 어떤 문제를 어떻게 해결했는지와 내 서비스에 어떻게 적용할 수 있을지 고민해야 함.
- Prefix Cache 등은 서버 측에서 구현해야 함.
