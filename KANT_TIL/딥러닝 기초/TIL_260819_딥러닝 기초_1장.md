

# 1-0강: 오프닝 - 딥러닝 기초 학습 로드맵

#### 딥러닝 학습 절차
코드 구조를 보고 구분할 수 있는 정도로 기억할 것
**데이터 → 모델 → 손실 → 최적화 → 평가**
```
문제 정의 
-> 데이터 준비 
-> 입력과 정답 구성 
-> 모델 설계 
-> 손실 함수 선택 
-> 옵티마이저 선택 
-> 학습 loop 실행 
-> 검증 loop 실행 
-> 성능 기록 
-> 모델 저장 
-> 추론
```


#### 모델 이해를 위한 질문
- 모델은 어떻게 입력을 받아 예측값을 만드나요?
- 예측값이 틀렸다는 것을 어떻게 숫자로 표현하나요?
- 손실이 작아지는 방향으로 파라미터는 어떻게 바뀌나요?
- 학습 데이터와 검증 데이터는 왜 나누나요?
- 모델 저장, 실험 기록, 재현성은 왜 중요할까요?

# 1-1강: 머신러닝과 딥러닝의 차이
## 규칙 기반 / 머신러닝 / 딥러닝 
### 규칙 기반
- 사람이 직접 조건 작성
- 표현이 규칙의 범위에서 벗어나면 놓칠 수 있음
### 머신러닝
- 사람이 특징 설계 -> 머신러닝 모델이 특징을 보고 규칙 학습
### 딥러닝
- 모델이 데이터 안에서 유용한 특징 표현을 학습  
- 딥러닝에 적합한 문제
	- 데이터가 많음 -> 복잡한 패턴 학습
	- 입력이 복잡 -> 이미지, 텍스트, 음성 등
	- 강한 비선형 관계 -> 단순 규칙으로 설명 불가
	- end-to-end 학습 유리 -> 전처리~예측까지 하나의 모델 흐름으로 학습


# 1-2강: 데이터-모델-손실-최적화-평가 흐름 (2)
### <학습 목표>
```
- 데이터, 모델, 손실 함수, 옵티마이저, 평가 루프가 연결되는 순서
- 학습 파이프라인의 각 단계 산출물
```

**데이터** 로드 -> **모델** 예측(model forward) -> **Loss** 계산 -> **Gradient** 계산(loss bacward) -> **Optimizer** 파라미터 업데이트 -> **Validation** 성능 확인

| Step | 코드                        | 의미                                |
| ---- | ------------------------- | --------------------------------- |
| 1    | `optimizer.zero_grad()`   | 이전 batch에서 계산된 gradient를 초기화합니다.  |
| 2    | `model(batch_x)`          | 현재 batch에 대한 예측값을 만듭니다.           |
| 3    | `loss_fn(preds, batch_y)` | 예측값과 정답의 차이를 계산합니다.               |
| 4    | `loss.backward()`         | loss를 기준으로 gradient를 계산합니다.       |
| 5    | `optimizer.step()`        | gradient를 사용해 parameter를 업데이트합니다. |

### 학습 파이프라인
```
1. DataLoader에서 batch 꺼내기
2. optimizer.zero_grad()
3. model로 예측값 생성
4. loss_fn으로 loss 계산
5. loss.backward()
6. optimizer.step()
7. validation loss 계산
```


# 1-3강: 딥러닝 문제 유형과 입출력 구조 설계

#### <학습 목표>
```
- 회귀, 이진 분류, 다중 분류 문제에서 입력 데이터와 예측 대상 구분
- 표 데이터, 이미지 데이터, 시퀀스 데이터 입력 형태 구분
- 문제 유형에 따라 모델 출력 형태와 손실 함수 연결
```


##### 문제 유형 정하기
- 숫자 예측? -> 회귀 (ex. 다음 달 구매 금액 예측)
- 두 가지 중 하나 선택? -> 이진 분류 (ex. 고객 이탈 여부)
- 여러 클래스 중 하나 선택? -> 다중 분류 (ex. 고객문의 주제 분류 - 배송/환불/결제/계정)

##### 문제 유형에 따른 결과 항목
- 정답 y의 형태
- 모델 마지막 출력층
- 손실 함수
- 평가 지표
- 예측 후처리 방식
