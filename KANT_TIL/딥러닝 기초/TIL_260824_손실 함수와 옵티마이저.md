# 딥러닝 모델 학습 핵심 정리

## 1. 모델의 전체 구조와 학습 흐름

```text
입력 데이터
    ↓
Backbone
특징 추출
    ↓
Head
예측값 출력
    ↓
Loss 계산
    ↓
backward()
Gradient 계산
    ↓
Optimizer
가중치 수정
```

```python
optimizer.zero_grad()  # 이전 Gradient 초기화
output = model(x)      # 예측값 계산
loss = criterion(output, y)
loss.backward()        # Gradient 계산
optimizer.step()       # 가중치 수정
```

- `backward()`는 Gradient만 계산함
- `optimizer.step()`이 실제 가중치를 수정함
- `zero_grad()`는 이전 Gradient가 누적되지 않도록 초기화함

## 2. Backbone과 Head

| 구분 | 역할 | 예시 |
|---|---|---|
| Backbone | 입력 데이터에서 특징 추출 | CNN, Transformer, 은닉층 |
| Head | 특징을 현재 문제의 출력으로 변환 | 회귀층, 분류층, LM Head |

```text
입력 -> Backbone -> 특징 벡터 -> Head -> 예측값
```

사전학습 모델을 Fine-tuning할 때는 보통 Backbone은 기존 지식을 보존하기 위해 작은 Learning Rate를, 새로 만든 Head는 빠르게 학습하기 위해 큰 Learning Rate를 적용할 수 있음.

```python
optimizer = torch.optim.AdamW([
    {"params": model.backbone.parameters(), "lr": 1e-5},
    {"params": model.head.parameters(), "lr": 1e-3}
])
```

## 3. 문제 유형별 출력과 손실함수

| 문제 | 모델 출력 | 손실함수 | 최종 예측 |
|---|---|---|---|
| 회귀 | 연속적인 예측값 | `MSELoss` | 출력값 그대로 |
| 이진 분류 | Logit 1개 | `BCEWithLogitsLoss` | Sigmoid 후 Threshold |
| 다중 분류 | 클래스별 Logit | `CrossEntropyLoss` | 가장 큰 Logit의 클래스 |

### 용어 주의

- 회귀의 출력은 일반적으로 `logit`이 아니라 `raw output` 또는 `prediction`이라고 함
- Logit은 분류에서 확률로 변환하기 전의 점수임
- Logit의 범위는 `0~1`이 아니라 $-\infty \sim +\infty$
- Sigmoid를 통과한 값이 `0~1`의 확률임

## 4. 회귀: MSELoss

### MSE

**Mean Squared Error: 평균제곱오차**

$$
\operatorname{MSE}
=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2
$$

```text
실제값과 예측값의 차이
          ↓
오차 제곱
음수 제거 + 큰 오차 강조
          ↓
평균
```

예시:

```text
실제값: [10, 20]
예측값: [12, 17]
오차:   [ 2, -3]
```

단순 오차를 더하면 양수와 음수가 상쇄됨.

$$
2+(-3)=-1
$$

MSE는 제곱하여 상쇄를 방지함.

$$
\frac{2^2+(-3)^2}{2}=6.5
$$

> 절대값에서 음수가 나오는 것이 아니라 `예측값-실제값`이라는 단순 오차에서 음수가 발생함. MAE는 절대값을 사용하므로 음수가 발생하지 않음.

### MSE와 MSELoss

| 구분 | MSE | `nn.MSELoss` |
|---|---|---|
| 의미 | 평균제곱오차의 수학적 개념 | PyTorch 구현 클래스 |
| 계산 | 오차 제곱의 평균 | 같은 원리 |
| 자동미분 | 개념 자체에는 없음 | 계산 그래프와 연결 |
| 용도 | 손실 또는 평가 지표 | PyTorch 모델 학습 |

## 5. 이진 분류: BCEWithLogitsLoss

**Binary Cross Entropy With Logits Loss**

```text
모델 출력 Logit
범위: -∞ ~ +∞
        ↓ Sigmoid
확률
범위: 0 ~ 1
        ↓ BCE
정답 0 또는 1과 비교
```

$$
p=\operatorname{Sigmoid}(z)
$$

$$
\operatorname{BCE}
=-[y\log(p)+(1-y)\log(1-p)]
$$

- 정답이 1이면 확률이 1에 가까울수록 Loss 감소
- 정답이 0이면 확률이 0에 가까울수록 Loss 감소
- 확신하면서 틀릴수록 Loss가 크게 증가

`BCEWithLogitsLoss`는 개념적으로 `Sigmoid + BCELoss`를 결합한 함수이므로 모델에 Sigmoid를 따로 넣지 않음.

```python
logits = model(x)
loss = criterion(logits, y)
```

최종 예측할 때만 Threshold를 사용함.

```python
probabilities = torch.sigmoid(logits)
predictions = (probabilities >= 0.5).long()
```

Sigmoid 확률 `0.5`는 Logit `0`과 같음.

```python
predictions = (logits >= 0).long()
```

## 6. 다중 분류: CrossEntropyLoss

**Cross Entropy Loss: 교차 엔트로피 손실**

클래스가 3개라면 데이터 하나마다 Logit 3개를 출력함.

```text
클래스별 Logit
      ↓ Softmax
합이 1인 클래스별 확률
      ↓ Cross Entropy
정답 클래스에 부여한 확률 평가
```

$$
p_c=\frac{e^{z_c}}{\sum_j e^{z_j}}
$$

정답 클래스가 $y$라면:

$$
\operatorname{CrossEntropyLoss}=-\log(p_y)
$$

| 고양이 | 강아지(정답) | 새 | Loss |
|---:|---:|---:|---:|
| 0.05 | 0.90 | 0.05 | 0.105 |
| 0.48 | 0.51 | 0.01 | 0.673 |
| 0.90 | 0.05 | 0.05 | 2.996 |

```text
정답 확률이 높음 -> Loss가 작음
정답 확률이 낮음 -> Loss가 큼
```

`CrossEntropyLoss`는 내부적으로 Softmax를 처리하므로 모델에 Softmax를 따로 넣지 않음.

```python
logits = model(x)             # (데이터 수, 클래스 수)
loss = criterion(logits, y)   # y는 클래스 번호
predictions = logits.argmax(dim=1)
```

- 다중 분류에서는 일반적으로 `0.5` Threshold를 사용하지 않음
- 가장 큰 Logit을 가진 클래스를 선택함
- 여러 클래스가 동시에 정답인 다중 레이블 분류에는 `BCEWithLogitsLoss`를 사용함

## 7. Loss, Validation Loss, Metric

| 구분 | 계산 데이터 | 가중치 수정 | 목적 |
|---|---|---:|---|
| Training Loss | 학습 데이터 | O | 모델 학습 |
| Validation Loss | 검증 데이터 | X | 모델 선택·과적합 확인 |
| Metric | 검증·테스트·업무 데이터 | X | 성능·업무 목표 평가 |

### Training Loss

```text
예측 -> Loss 계산 -> backward() -> 가중치 수정
```

### Validation Loss

별도의 함수가 아니라 학습에 사용한 것과 같은 Loss 함수를 검증 데이터에 적용한 값임.

```text
Training Loss   = Loss 함수(학습 데이터)
Validation Loss = 같은 Loss 함수(검증 데이터)
```

Validation Loss로는 `backward()`나 가중치 수정을 하지 않음.

### Metric

```text
분류: Accuracy, Precision, Recall, F1, AP
회귀: MAE, RMSE
업무: 탐지율, 비용 절감액, 처리시간
```

```text
Loss            -> 무엇을 최소화하며 학습할 것인가?
Validation Loss -> 새로운 데이터에도 안정적인가?
Metric          -> 실제 업무 목적을 달성했는가?
```

가장 낮은 Validation Loss 모델이 항상 가장 좋은 업무 모델은 아니므로 업무 Metric을 함께 확인해야 함.

## 8. Loss와 Gradient

- **Loss**: 현재 예측 오차의 크기
- **Gradient**: 가중치를 움직였을 때 Loss가 어느 방향으로 얼마나 변하는지 나타내는 기울기

Gradient가 0이라고 해서 Loss가 반드시 0인 것은 아님.

$$
L(w)=(w-2)^2+5
$$

$$
\frac{dL}{dw}=2(w-2)
$$

$w=2$일 때:

$$
\frac{dL}{dw}=0,\qquad L(2)=5
$$

```text
Gradient = 0
├─ 최소점
├─ 최대점
├─ 안장점
├─ 평평한 구간
└─ Dead ReLU로 Gradient 전달 차단
```

> Loss 0은 오차가 없다는 뜻이고, Gradient 0은 현재 위치에서 Loss를 줄일 방향을 찾기 어렵다는 뜻임.

## 9. Gradient가 0인 해를 직접 구하지 않는 이유

딥러닝도 이론적으로는 다음 조건을 만족하는 가중치를 찾는 문제임.

$$
\nabla L(\theta)=0
$$

하지만 딥러닝 모델은:

- 가중치가 수천만·수십억 개일 수 있음
- 여러 층과 비선형 함수로 연결됨
- 수많은 학습 데이터의 오차가 포함됨
- Gradient가 0인 지점이 매우 많음
- 비선형 연립방정식을 직접 풀기 어려움

따라서 해를 직접 구하지 않고 현재 위치에서 Gradient를 계산하며 최소점 근처로 이동함.

```text
초기 가중치
    ↓
Gradient 계산
    ↓
반대 방향으로 이동
    ↓
새 위치에서 재계산
    ↓
반복
```

## 10. Gradient와 Learning Rate

$$
\theta_{\text{new}}
=
\theta_{\text{old}}
-\eta\nabla L(\theta)
$$

- Gradient: 이동 방향과 현재 경사의 크기
- Learning Rate $\eta$: 실제 이동 거리의 배율
- 실제 변경량: `Learning Rate × Gradient`

예시:

```text
현재 가중치 = 4
Gradient = 8

Learning Rate 0.1  -> 4-(0.1×8)  = 3.2
Learning Rate 0.01 -> 4-(0.01×8) = 3.92
```

- 너무 크면 최소점을 지나쳐 진동하거나 발산함
- 너무 작으면 안정적이지만 학습이 느림
- Learning Rate는 Gradient 자체를 변경하는 것이 아니라 가중치 이동량을 조절함

## 11. SGD와 Adam

### SGD

**Stochastic Gradient Descent: 확률적 경사하강법**

| 단어 | 의미 |
|---|---|
| Stochastic | 무작위로 선택한 일부 데이터 사용 |
| Gradient | Loss의 기울기 |
| Descent | Gradient 반대 방향으로 이동 |

$$
\theta_{t+1}=\theta_t-\eta g_t
$$

`Stochastic`은 가중치를 무작위 방향으로 움직인다는 뜻이 아니라, Gradient 계산에 사용할 데이터를 무작위로 선택한다는 뜻임.

### Adam

**Adaptive Moment Estimation: 적응적 모멘트 추정**

| 단어 | 의미 |
|---|---|
| Adaptive | 파라미터별 이동 크기 조절 |
| Moment | Gradient 평균과 제곱 평균 |
| Estimation | 이동평균으로 계속 추정 |

첫 번째 Moment는 Gradient의 평균적인 방향을 추정함.

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t
$$

두 번째 Moment는 Gradient 크기를 추정함.

$$
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2
$$

$$
\theta_{t+1}
=
\theta_t-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}
$$

| 구분 | SGD | Adam |
|---|---|---|
| Gradient 정보 | 현재 Gradient 중심 | 현재·과거 Gradient |
| 이동량 | 기본 LR 적용 | 파라미터별 조절 |
| 특징 | 단순하고 메모리 사용이 적음 | 초기 학습이 빠르고 설정이 쉬움 |

## 12. 회귀 출력층의 ReLU

```text
은닉층 ReLU
-> 비선형성을 추가하여 복잡한 관계 학습

출력층 ReLU
-> 최종 예측값을 0 이상으로 제한
```

출력층에 ReLU를 항상 사용하는 것은 아니며 정답값의 범위에 따라 결정함.

| 정답값 범위 | 출력층 처리 | 예시 |
|---|---|---|
| 음수·양수 가능 | 활성화 함수 없음 | 수익·손실, 온도 변화량 |
| 0 이상이며 0도 정상 | ReLU 가능 | 강수량, 수요량, 방문자 수 |
| 반드시 0보다 큼 | Softplus 등 | 배송시간, 수명, 농도 |
| 0~1 | Sigmoid | 비율 |

### ReLU를 사용할 수 있는 예

태양광 발전량에서 `0`은 발전하지 않은 정상 상태임.

```text
raw output = -0.2
        ↓ ReLU
prediction = 0
```

비슷한 예:

- 강수량 0 -> 비가 오지 않음
- 수요량 0 -> 주문이 없음
- 방문자 수 0 -> 방문자가 없음
- 생산량 0 -> 생산하지 않음
- 태양광 발전량 0 -> 발전하지 않음

### ReLU의 한계

$$
-0.1,\;-3,\;-100
\xrightarrow{\operatorname{ReLU}}
0
$$

모든 음수를 0으로 만들기 때문에 다음을 구분하지 못함.

- 실제 0을 예측한 경우
- 작은 음수가 잘린 경우
- 큰 음수가 잘린 경우

ReLU는 오류를 탐지하는 함수가 아니라 출력 범위를 0 이상으로 제한하는 함수임.

또한 음수 구간에서는 Gradient가 0이므로 학습이 막힐 수 있음. `0`도 불가능하다면 항상 양수를 출력하는 Softplus를 사용할 수 있음.

```python
raw_output = self.fc2(hidden)
prediction = F.softplus(raw_output) + 1e-6
```

배달시간의 `0`이 미시작·결측·기록 오류를 의미한다면 시간값 0으로 학습하지 않고 상태를 별도로 관리해야 함.

```text
delivery_status = "not_started"
delivery_time = 결측값
```

## 13. 최종 핵심 구분

```text
Loss 값 ≠ Gradient 값
Gradient 0 ≠ 반드시 Loss 0
Logit ≠ 확률
Learning Rate ≠ Gradient
backward() ≠ 가중치 수정
ReLU 출력 ≠ 오류 탐지
```
