## 1. 데이터 처리 및 토큰 예측

- `collate`: 여러 데이터 행을 하나의 배치로 묶는 함수
  - 길이가 다른 데이터의 빈 부분에 Padding 적용
  - `attention_mask`로 실제 토큰과 패딩 구분
- 다음 토큰 예측: 모델이 이전 토큰을 바탕으로 다음 토큰 예측
- 학습 시에는 Decoding하지 않고 Logits와 정답 토큰을 비교하여 Loss 계산

## 2. GPU 및 학습 환경

- GPU 사용 시 Out of Memory(OOM) 발생 가능
  - BF16(Bfloat16): GPU 메모리 사용량을 줄이기 위한 16비트 부동소수점 형식
- GPU 인스턴스 유지 및 운영 시간 고려
  - 미국의 비업무 시간 등을 활용한 GPU 자원 운영 검토
- GPU에서 사용하지 않는 객체와 캐시 메모리 정리

```python
gc.collect()
torch.cuda.empty_cache()
```

## 3. TrainingArguments

- `max_steps`: 전체 가중치 갱신 횟수
- `per_device_train_batch_size`: GPU당 한 번에 처리하는 데이터 수
- `gradient_accumulation_steps`: 여러 미니배치의 기울기를 누적한 뒤 한 번 갱신
  - 매번 가중치를 갱신하면 개별 문항에 따라 갱신 방향이 크게 달라질 수 있음
  - 기울기 4개를 누적하여 한 번 갱신하는 방식 적용
  - `max_steps=24`, `gradient_accumulation_steps=4`, 배치 크기 1 → 총 96개 문항 처리
  - 데이터셋 48개 기준 2 Epoch
- `learning_rate`: 가중치 갱신에 사용하는 학습률
- `lr_scheduler_type`: 학습 진행에 따른 학습률 변경 방식

### 학습 단계 설정

- `TOTAL_STEPS`: 전체 가중치 갱신 횟수
- `PAUSE_STEP`: 학습을 일시 중단할 단계

### Optimizer

- `AdamW`: 기울기를 이용하여 가중치를 갱신하는 대표적인 Optimizer
- 학습률은 Scheduler와 함께 조정
- 추가 학습: AdamW의 원리 및 동작 방식
