### 1. 정상 = Positive

- Recall, Precision, Accuracy 점수가 다 높다. -> 데이터 불균형이라고 판단할 수 있는가? 판단할 수 없다.

### 2. 암 환자 = Positive
![](../../첨부파일/260814_암환자_Positive%20설정.png)

- 암 환자를 찾아내야 하는데, 모두 정상이라고 하면 한 명도 찾아내지 못해서 0이 된다. 
- **우리가 찾고자 하는 대상을 Positive로 설정하고, Recall 점수가 낮을 때 잘 찾아내지 못했다고 판단하면 된다.**

- Precision : 양성이라고 예측한 것 중 실제 양성의 비율
- **Recall : 실제 양성 중 찾아낸 비율**

# 수업2) 4장 2강: 교차검증 전략과 데이터 누수 방지

```
가장 중요한 전제가 하나 있습니다. 일반 KFold는 각 행을 대체로 독립이라고 봅니다. 같은 문서의 chunk나 같은 대화의 turn처럼 서로 닮은 행이 반복된다면, validation 위치만 바꾸는 것으로는 충분하지 않습니다.
```

Q. `같은 대화의 turn`처럼 서로 닮은 행
`같은 대화의 turn` 의미
A. 대화에서 한 번의 발화(메시지)
```
사용자: 랜덤포레스트가 뭐야?        ← Turn 1
AI: 여러 결정트리를 결합한 모델...  ← Turn 2
사용자: 왜 여러 개를 사용해?        ← Turn 3
AI: 분산을 줄이기 위해서...          ← Turn 4
```

*행 단위로 무작위 KFold*하면, 같은 대화의 일부가 Train에도 있고, Validation에도 들어갈 수 있음 -> **데이터 누수(Data Leakage)** 발생
