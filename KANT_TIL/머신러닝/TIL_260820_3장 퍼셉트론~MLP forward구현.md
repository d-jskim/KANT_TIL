

# 3-3 가중치/편향과 nn.Linear
nn.Linear(3, 5)일 때 내부적으로 weight shape(5, 3) <weight shpae(out_features, in_features)>이 생기는 이유? 
```
입력 노드 3개                 출력 노드 5개

x₁ ───────────────┬────────→ y₁
x₂ ───────────────┼────────→ y₂
x₃ ───────────────┼────────→ y₃
                  ├────────→ y₄
                  └────────→ y₅
```

$$y_1​=x_1​w_{11}​+x_2​w_{12}​+x_3​w_{13}​+b_1​$$
$$y_2​=x_1​w_{21}​+x_2​w_{22}​+x_3​w_{23}​+b_2​$$
```
y1 - 출력 1용 가중치 → [w₁₁, w₁₂, w₁₃]
y2 - 출력 2용 가중치 → [w₂₁, w₂₂, w₂₃]
y3 - 출력 3용 가중치 → [w₃₁, w₃₂, w₃₃]
y4 - 출력 4용 가중치 → [w₄₁, w₄₂, w₄₃]
y5 - 출력 5용 가중치 → [w₅₁, w₅₂, w₅₃]
```

![](../../첨부파일/260820_nn.Linear내부%20가중치.png)


-  nn.Linear(3, 5)에 입력이 3, 출력이 5이기 때문에 가중치도 in_features인 3이 먼저 와야할 것 같지만, 위와 같은 이유로 (out_features, in_features)로 입력하고, 계산시에 transpose하여 사용함. 
- 즉, 가중치 3개를 한 행에 표현하고, 출력에 필요한 가중치 행이 5개이기 때문에 (5, 3) shape을 갖게 된다.
