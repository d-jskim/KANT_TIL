

# 2장 2강: 부스팅 계열 모델의 원리와 발전

####  예시: RAG 품질 평가 모델
RAG 품질 평가는 Retrieval과 Generation을 분리하고, Context와 Answer의 품질을 각각 평가하여 전체 RAG 성능을 판단한다.
#### RAG 품질 평가
-> 검색 품질(Retrieval) + 생성 품질(Generation) + 검색-생성 연계 품질

- **대표 평가 지표**

| 구분  | 항목                     | 설명                         |
| --- | ---------------------- | -------------------------- |
| 검색  | **Context Relevance**  | 검색된 문서가 질문과 관련되는 정도        |
| 검색  | **Context Recall**     | 답변에 필요한 정보가 검색 결과에 포함되는 정도 |
| 생성  | **Faithfulness**       | 생성 답변이 검색 문서의 내용에 근거하는 정도  |
| 생성  | **Answer Relevance**   | 생성 답변이 사용자 질문에 적절하게 답하는 정도 |
| 종합  | **Answer Correctness** | 생성 답변이 실제 정답과 일치하는 정도      |


- **핵심 구조**

$$
사용자 질문 
↓ 
Retriever 
↓
검색 문서 ──→ Context Relevance / Recall 
↓
LLM 
↓ 
생성 답변 ──→ Faithfulness / Answer Relevance 
↓
정답 비교 ──→ Answer Correctness
$$

- **RAGAS(RAG Assessment)**
	- `Faithfulness`, `Answer Relevancy`, `Context Precision`, `Context Recall`

## 1. 약한 학습기 (Weak learner)



### 1.1 AdaBoost

## Ⅰ. 개요

### 주제어 요약구
약한 학습기 가중 결합 앙상블

### 개념(압축)
약한 학습기를 순차적으로 학습시키며 오분류 데이터의 가중치를 높여 여러 학습기를 결합하는 Boosting 알고리즘

### 개념(요약)
약한 학습기를 반복 학습하면서 이전 단계의 오분류 데이터에 높은 가중치를 부여하여 최종 예측 성능을 향상시키는 앙상블 학습 기법

### 개념(상세)
AdaBoost는 여러 개의 약한 학습기를 순차적으로 학습시키면서 이전 학습기에서 오분류된 데이터의 가중치를 증가시키고, 각 학습기의 성능에 따라 가중치를 부여하여 최종적으로 약한 학습기들의 예측을 결합하는 Boosting 기반 앙상블 기법이다.

### 개념(설명)
처음에는 모든 학습 데이터를 동일한 중요도로 취급하고, 학습기가 데이터를 잘못 분류하면 해당 데이터의 가중치를 높인다. 이후 학습기는 오분류된 데이터에 더 집중하여 학습하며, 이러한 과정을 반복한 후 여러 학습기의 예측을 가중 결합하여 최종 결과를 결정한다.

### 목적
- 약한 학습기의 반복 결합을 통한 분류 성능 향상
- 오분류 데이터에 대한 학습 집중
- 여러 학습기의 결합을 통한 일반화 성능 향상

### 특징(3개)
1. 순차 학습
2. 오류 집중
3. 가중 결합

### 특징 표

| 항목 | 설명 |
|---|---|
| 순차 학습 | 이전 학습 결과를 다음 학습 과정에 반영 |
| 오류 집중 | 오분류 데이터의 가중치를 증가시켜 재학습 |
| 가중 결합 | 학습기별 성능에 따라 가중치를 적용하여 최종 예측 |

### 개요 요약
약한 학습기 → 오분류 가중치 증가 → 반복 학습 → 가중 결합

### 개요 상세 요약
각 단계에서 이전 학습기의 오류를 반영하여 학습 데이터의 중요도를 조정하고, 학습기별 가중 투표를 통해 최종 분류 결과를 결정한다.

### 구성도 요약

| 구분 | 항목 | 설명 |
|---|---|---|
| 학습 | 학습 데이터 | 반복 학습에 사용되는 입력 데이터 |
| 학습 | 약한 학습기 | 낮은 복잡도의 분류기를 순차적으로 학습 |
| 가중치 | 데이터 가중치 | 각 학습 데이터의 중요도를 나타내는 가중치 |
| 가중치 | 학습기 가중치 | 각 약한 학습기의 성능에 따라 부여되는 가중치 |
| 결합 | 가중 투표 | 학습기별 가중치를 반영하여 최종 분류 결과 결정 |

### 구성요소 요약
데이터 가중치 조정 + 약한 학습기 순차 학습 + 학습기 가중 결합
