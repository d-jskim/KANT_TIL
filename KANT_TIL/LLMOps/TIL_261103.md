- 예외 케이스를 찾아서 테스트
  - rows가 빈 리스트인 경우 -> metrics 계산 시 len(rows)이 분모일 때 길이가 0인 경우 등
- 지연될 경우, UI 로딩화면 / status 공유(예시: 응답 준비 중)로 보완
- 반응 속도(지연 낮춤)를 위해서는 컨텍스트 최소화, 답변 품질 높이고 싶으면 컨텍스트 추가.
- 사용자 피드백을 받아서 강화학습 가능
- 피드백에서 우선순위를 정해서 서비스 개선(전체를 한번에 반영하면 출시 기간 늦어짐) -> 답변 정확도와 답변 속도는 trade-off
- 가능하면, 하나의 플랫폼에서 운영지표 관리할 것
- `job-skill matching` 프로젝트에서 어떻게 피드백을 받을지?
	- 매칭했을 때, 어느 정도 적합한지 사용자가 피드백
	- 사용자의 직무 프로필에서 지원했던 회사의 합격/불합격 여부 기록
